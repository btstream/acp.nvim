*acp.nvim*  与 Agent 对话，界面参照 Zed 的 Agent Panel

==============================================================================
1. 简介                                                        *acp-intro*

acp.nvim 是一个 Neovim 原生的 Agent Client Protocol 客户端。
它不是把 Agent 的 TUI 嵌进终端窗口，而是用 buffer、split 和 extmark
自己渲染对话记录、工具调用和输入框。

默认连接 OpenCode：

    :!opencode auth login
    :Acp

==============================================================================
2. 命令                                                      *acp-commands*

:Acp [子命令]                                               *:Acp*
    toggle       打开或隐藏面板（默认）
    open         打开面板，必要时启动 Agent
    hide         隐藏面板，不中断会话
    new          新建会话
    stop         中止当前回合
    sessions     打开会话浏览器（<CR> 切换，<C-d> 删除，输入即过滤）
    delete       同 sessions，直接进入删除流程
    model        切换模型
    mode         切换模式
    reconnect    重连并恢复当前会话
    disconnect   停止 Agent 进程
    permission   重新打开待确认的权限请求
    file         把当前文件附加到输入区
    diagnostics  把当前 buffer 的诊断附加到输入区

:AcpLog                                                      *:AcpLog*
    打开日志文件。

:AcpDebug                                                  *:AcpDebug*
    在命令行打印控制器状态。

==============================================================================
3. 输入区                                                    *acp-composer*

<C-s>          发送；回合进行中且输入为空时改为中止
q              隐藏面板
<C-x><C-u>     补全 /命令 与 @文件
@path/to/file  发送时自动展开为附件
<M-m>          切换模型（输入模式）
<M-b>          切换模式（输入模式）
M / m          切换模型 / 模式（普通模式）

模型和模式也可以直接点击 winbar 上带 ▾ 的名称。选择器支持输入关键字
模糊过滤，适用于模型数量很多的 Agent。

每个会话有独立的草稿和附件。面板隐藏后草稿仍保留。

==============================================================================
4. 转录区                                                  *acp-transcript*

i / <C-s>      聚焦输入区
<CR>           打开光标所在位置的文件
<Tab>          展开或折叠工具调用
[b / ]b        上一个 / 下一个消息块
G / gg         最新 / 最早
S              附加当前选区
F              附加当前文件
R              附加诊断
M / m          选择模型 / 模式
<C-n>          新建会话
L              历史会话
g?             帮助
q              隐藏面板

所有按键都是 buffer-local。

5. 配置                                                      *acp-config*

    require("acp").setup({
      agent = "opencode",
      agents = {
        opencode = { command = "opencode", args = { "acp" } },
      },
      layout = {
        backend = "native",   -- "native" | "external"
        position = "right",
        width = 0.38,
        min_width = 42,
        max_width = 120,
        input_height = 8,
        lock_buffer = true,   -- 用 'winfixbuf' 锁定 ACP 窗口
      },
      ui = {
        icons = true,
        show_thoughts = false,
        language = "zh",
        picker = "vim",       -- "vim" | "internal"
        session_picker = "snacks", -- "snacks" | "internal"
        zed_style = true,
        title = { placement = "auto" },
        toolbar = { placement = "auto", show_usage = false },
      },
      keymaps = {
        send = "<C-s>",
        cancel = "<C-c>",
        close_panel = "q",
        focus_input = "i",
        open_location = "<CR>",
        prev_block = "[b",
        next_block = "]b",
        toggle_block = "<Tab>",
      },
      permissions = { prompt = "select" },
      log = { level = "warn", protocol = false },
    })

可用字段与完整说明见 README。

6. 与 edgy.nvim 集成                                          *acp-edgy*

    require("acp").setup({ layout = { backend = "external" } })

    -- edgy 配置
    opts = function(_, opts)
      require("acp.integrations.edgy").extend(opts)
    end

两个视图必须作为数组元素写进列表，不能写成具名字段。edgy 只遍历
ipairs(views)，具名字段会被完全忽略，导致输入框脱离 edgebar、布局错位：

    -- 正确
    right = {
      { ft = "acp_chat",  title = "Agent" },
      { ft = "acp_input", title = "Message", size = { height = 0.2 } },
    }

    -- 错误
    right = {
      { ft = "acp_chat", title = "Agent" },
      input = { ft = "acp_input", title = "Message" },
    }

无法接管时 acp.nvim 会给出警告。

acp 创建两个普通视图：

    acp_chat    对话记录（只读）
    acp_input   输入区（可编辑）

由 edgy 决定它们的位置和尺寸。acp 不会持续调整窗口大小，也不会在窗口
被关闭后强行重开。

默认 acp 拥有两个 winbar。若想让 edgy 显示标题栏：

    require("acp.integrations.edgy").views({ title_winbar = true })

==============================================================================
7. 状态栏                                                  *acp-statusline*

acp.nvim 不修改 'statusline' 和 'laststatus'。交互信息全部放在输入窗口的
winbar 中，因此 laststatus=3（全局状态栏）下也能正常显示。

需要集成到自己的状态栏时：

    require("acp").statusline()   -- "◆" / "◆ ◌" / "◆ !"
    require("acp").status()       -- 结构化表

==============================================================================
8. 窗口保护与选择器                                        *acp-protection*

ACP 的两个窗口默认锁定到自己的 buffer（'winfixbuf'），:edit、:bnext 等操作
无法把对话记录或输入框替换成其它文件。关闭窗口与隐藏面板不受影响。

从面板 :split 会得到一个可用的普通窗口，而不是被锁死的副本。

需要关闭该行为：

    require("acp").setup({ layout = { lock_buffer = false } })

所有选择器（模型、模式、会话、权限确认）默认通过 vim.ui.select 实现，
因此 telescope、fzf-lua、snacks.nvim 等插件会自动接管。需要改用内置浮动
选择器时：

    require("acp").setup({ ui = { picker = "internal" } })

==============================================================================
9. 工作目录                                                  *acp-cwd*

会话的工作目录默认与 Neovim 的 cwd 一致（vim.fn.getcwd()），可用 cwd 配置项
显式固定。:Acp sessions 的列表按该目录过滤；若为空，会自动退回展示 Agent 知道
的所有会话。

切换历史会话时使用该会话自己的目录发起 session/load，因为 ACP 规范要求 cwd 与
会话一致，不匹配时 Agent 会拒绝。

10. 面板尺寸                                                    *acp-sizing*

layout.width 为 0~1 时按编辑器宽度取比例，>1 时为绝对列数，受 min_width /
max_width 约束，且不超过编辑器宽度 60%。

构建面板时临时关闭 'equalalways'，两个窗口创建完并设置好尺寸后再恢复；否则
第二次 split 会立即重排，覆盖配置的宽度。

winbar 上的模型/模式点击区域需要 'mouse' 含 a（Neovim 默认 "nvi" 不含 a）。
无法点击时使用 <M-m> / <M-b>，acp.nvim 会在启动时提示一次。

11. 会话标题与删除                                      *acp-session-titles*

标题显示在对话记录窗口的 winbar 中。OpenCode 不会主动推送 session_info_update，
标题只出现在 session/list 结果里。acp.nvim 在会话创建后、切换会话后、以及每回合
结束后各查询一次列表来同步，并用 session id 做缓存，因此切换后标题立即更新。

:Acp sessions 默认使用 snacks.nvim 的 picker：自带 fuzzy 搜索、实时预览，并沿用
用户已有的 snacks 主题。未安装 snacks 时自动回退到内置窗口。

    <CR>        切换会话
    <C-d>       删除会话（二次确认）
    输入        fuzzy 过滤
    <Esc>/q     关闭

列表右侧显示更新时间，当前会话行首有箭头标记，右侧预览显示完整会话 ID、目录与
时间。删除后列表原地刷新，可连续删除。

强制使用内置窗口：

    require("acp").setup({ ui = { session_picker = "internal" } })

内置窗口（回退时）支持 j/k 移动与 <BS>/<C-u> 编辑过滤。

删除非当前会话不影响当前对话；删除当前会话会自动新建一个。Agent 未声明
sessionCapabilities.delete 时给出提示，不弹出无法兑现的确认框。

12. 行为细节                                                *acp-behavior*

同一会话同时只运行一个 prompt；生成中提交的消息本地排队。

Agent 崩溃后使用 :Acp reconnect。重连会通过 session/load 重放 Agent 侧
历史，但不会自动重发上一条 prompt。

未发送的草稿保存在 stdpath("state")/acp/drafts.json，重启后自动恢复。

权限选择器按 Esc 或 q 关闭视为拒绝；若 Agent 没有提供 reject 选项，则返回
cancelled。

13. 高亮                                                    *acp-highlights*

所有样式通过语义化高亮组暴露，例如：

    AcpUser  AcpAssistant  AcpToolTitle  AcpToolRunning
    AcpToolSuccess  AcpToolError  AcpPlan  AcpSeparator
    AcpTitle  AcpToolbar  AcpPermission  AcpStreaming

直接覆盖即可：

    vim.api.nvim_set_hl(0, "AcpUser", { link = "Function" })

ui.icons = false 会改用 ASCII 图标。

    :checkhealth acp
